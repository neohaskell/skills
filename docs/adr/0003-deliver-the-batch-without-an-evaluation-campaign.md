# Deliver the batch without an evaluation campaign

Delivery preserves the agreed 96 skills, the full change matrix for the 27 historical entries, and their P1 corrections. The new capabilities discover application context and compatible guidance, connect API contracts to clients, and complete the requested UI journey using the consumer's technology. Work starts with P1 corrections, continues with imports and resources, and finishes with the new capabilities and distribution documentation.

Nick explicitly removed Jev and checks, verification, and evaluations as delivery work in order to focus on shipping the batch. This supersedes his earlier acceptance of five scenarios in both agents and the previous acceptance gates. No evaluation infrastructure, consumer suite, or v1 certification is required. Catalog skills about tests and review retain their responsibilities. Update file protections remain part of `nh-skills` behavior without becoming a batch acceptance campaign.

The [final scope decision agreed with Nick](https://plane.p.egregore.io/egregore/projects/5535680e-e3f6-4023-b400-2b27544130e2/issues/f1e10d4b-d63f-458f-a88c-ea94ab966038/) records the amendment. This ADR records planning; it does not claim implementation, executed tests, or publication.
