# Distribute the complete collection at a fixed version

The mandatory pinned first-install procedure and requirement to install both agents are superseded by [ADR 0004](0004-simplify-first-installation.md). The procedure below remains available for explicit release-pinned installations.

The collection is published from this repository through immutable tags, starting at `v1.0.0`, and installed in full by commit SHA using a tested version of `npx skills`. Compatible fixes are patch releases, compatible capabilities are minor releases, and renames, removals, or breaking changes are major releases. Consumers commit the installed content, lockfile, and Claude links to the canonical Codex copy because the installer does not resolve dependencies between skills or guarantee reconstruction of both destinations from the lockfile alone. One maintenance skill guides explicit updates and recovery, preserving separate extensions and stopping for custom changes. Selective installation, an additional public helper command, and Neo CLI skill management are outside the contract.

The collection version does not replace the authority of the API guide matched to the effective framework revision. The [distribution decision agreed with Nick](https://plane.p.egregore.io/egregore/projects/5535680e-e3f6-4023-b400-2b27544130e2/issues/c584e37d-362b-424c-a13a-a3d757261c08/) contains the contract and evidence. This ADR records the planning decision; it is not implementation evidence.
