# UI route

Read [nh-frontend](../../nh-frontend/SKILL.md) after locating the component, route, design system, and execution command. Preserve the consumer's stack. Implement the requested view and applicable loading, error, empty, permission, navigation, and retry states. Observe the requested interaction at its actual route with available tools. A copy or color change does not require an event model or a new backend slice.
